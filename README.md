# Encrypted Chat App (AES-CBC Socket Implementation)

This project is a secure Client-Server chat utilizing **TCP Sockets** combined with **Symmetric AES-256-CBC encryption**. It mimics standard tutorials for Python AES socket communications, ensuring that all data sent over the network is properly encrypted and padded.

## Features

1. **Client/Server Socket Chat**: Structured with `server.py` and `client.py` using Python `socket` logic for a 1-to-1 secure connection.
2. **AES-CBC Encryption**: All communications are symmetrically encrypted using `pycryptodome`. Texts are padded using PKCS7 and encrypted with a 256-bit AES key in CBC mode.
3. **Pre-shared Key (PSK)**: A 32-byte key is automatically generated and saved to `shared.key` upon the first run. Both the server and the client must have access to this same `shared.key` file in their working directory to communicate.
4. **Dynamic IVs (Nonces)**: A 16-byte random Initialization Vector (IV) is safely generated by the cipher for every single encrypted message. This IV is prepended to the ciphertext before transmission over the socket, ensuring every message cipher is unique even if the plaintext is the same.
5. **Verbose Ciphertext Terminal Output**: To demonstrate that the encryption works, the scripts are configured to visually output the raw encrypted byte strings (`ciphertext`) being transmitted and received before decrypting them back into plaintext on the terminal.

## Usage Instructions

1. **Install requirements:** Install the `pycryptodome` library.
   ```bash
   pip install pycryptodome
   ```

2. **Launch Server:** Start the listening server. This will generate the cryptographic key (`shared.key`) if one is not already present.
   ```bash
   python server.py
   ```

3. **Launch Client:** In a new terminal window, run the client to connect to the listening server. Make sure `shared.key` is present in the same directory.
   ```bash
   python client.py
   ```

4. **Chat Securely**: After the connection is established, start typing in either window. You will see both the raw encrypted payload and the successfully decrypted strings in your terminal output.
